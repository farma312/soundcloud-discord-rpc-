# 🎵 SoundCloud Discord Rich Presence (zen_rpc)

Кастомный и легковесный клиент Discord Rich Presence для **SoundCloud**, написанный на **Rust** с графическим интерфейсом на **egui**.

---

## ✨ Возможности

- **Синхронизация в реальном времени:** точный прогресс-бар трека и отображение оригинальной обложки в профиле Discord.
- **Интерактивный плеер:**
  - 🎤 Вкладка караоке с автоматической синхронизацией строк (LRC).
  - ⚡ 60 FPS плавный неоновый аудио-визуалайзер (Equalizer).
  - 💿 Анимированная вращающаяся виниловая пластинка.
  - 🌌 Фоновые живые частицы (Sparks) с выбором направления полета (Вверх/Вниз).
- **Кастомизация UI:**
  - Темы: Kawaii (Pink), Neverlose (Cyan), Shadow Fiend (Ruby), SoundCloud (Orange).
  - 🎨 Встроенный редактор собственной темы с палитрой цветов.
  - Поддержка кастомных аватарок.
- **Мультиязычность:** Русский, English, Українська.
- **Статистика и история:** трекинг прослушиваний и экспорт красивой инфографики топа артистов в `.png`.
- **Умный буфер:** кнопка `📋` для копирования ссылки на трек друзьям в один клик.
- **Поддержка браузеров:** Google Chrome, Opera GX, Zen Browser, Microsoft Edge, Firefox, Яндекс Браузер.

---

## 🚀 Установка и настройка

1. Скачай последнюю версию `zen_rpc.exe` из раздела [Releases](https://github.com/farma312/soundcloud-discord-rpc-/releases).
2. Установи расширение **Tampermonkey** для своего браузера.
3. Добавь в Tampermonkey скрипт из файла [`soundcloud_rpc.user.js`](./soundcloud_rpc.user.js).
4. Запусти `zen_rpc.exe` и включи любой трек на SoundCloud!
